## Use it

Open the PDF that matches your game, or download it from the repository for
local use. The repository contains the finished PDFs only; it does not include
editable source files or a build process.

## Contributions and Updates

When adding or replacing a sheet, keep the filename descriptive and include the
updated PDF in the change. Note the game and sheet variant so readers can tell
which existing file, if any, it replaces.
